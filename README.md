# FinTrack — Full-Stack Expense & Income Tracker

Современное веб-приложение для контроля личных финансов. Позволяет пользователям вести учет доходов и расходов, динамически управлять категориями операций и анализировать историю транзакций в реальном времени.

---

## 🚀 Стек технологий

### Frontend (Client)
* **Core:** React, TypeScript, Vite
* **State Management:** Redux Toolkit (RTK)
* **Forms & Validation:** Zod
* **Styling:** SCSS Modules

### Backend & Database (Server)
* **Environment:** Node.js
* **Database ORM:** Prisma
* **API:** REST API

---

## 🛠️ Ключевой функционал

* **Учет транзакций:** Быстрое добавление расходов и доходов с автоматической фильтрацией категорий на лету.
* **Управление категориями:** Динамическое создание кастомных категорий отдельно для доходных и расходных операций.
* **Оптимизированный UI:** Исключены каскадные рендеры (cascading renders), вычисление активных стейтов происходит непосредственно во время рендера (derived state).
* **Умная история:** Фильтрация транзакций по поисковому запросу (название/категория) и вкладкам (Все / Доходы / Расходы).
* **Пагинация:** Пошаговая подгрузка истории операций по кнопке «Показать еще».

## 📦 Архитектура проекта

```
fintrack/
├── client/               # Фронтенд часть приложения (React + Vite)
│   ├── src/
│   │   ├── components/   # Переиспользуемые UI компоненты
│   │   ├── pages/        # Страницы (включая Transactions)
│   │   ├── store/        # Redux Toolkit slices и hooks
│   │   └── utils/        # Хелперы (валюты, форматирование)
├── server/               # Бэкенд часть (Node.js API)
└── prisma/               # Схема базы данных и миграции Prisma
```

## 🔧 Запуск локально
1. Клонирование репозитория
```
git clone https://github.com/LizKa2091/fintrack
```
```
cd fintrack
```
3. Настройка Бэкенда & Prisma
Перейди в корневую директорию сервера (server), установи зависимости и примени миграции:

```
cd server
npm install
npx prisma migrate dev
npm run dev
```
3. Настройка Фронтенда
В новом терминале перейди в папку клиента (client), установи зависимости:
```
cd client
npm install
npm run dev
```
